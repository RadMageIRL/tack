Labels

Rename a label to update every note that carries it. Renaming onto an existing label merges them. Deleting a label never deletes notes.

tack_

Keep-style notes and checklists, local-first. Everything is stored in this browser (local storage and IndexedDB). There is no account, nothing is uploaded, and tack contacts no other server. The one exception: Search text in pictures (off unless you turn it on) downloads its reader from cdn.jsdelivr.net when tack.html is opened as a file; opened from a website, tack loads it from that same website. That storage is the only copy unless you export: Data → Export backup writes one JSON file, and on Chrome/Edge Data → Save to file keeps a real file on disk in sync automatically.

Data → Backups takes automatic snapshots (on by default, daily - change or turn off there) that you can restore from, and can write full copies to a backup folder on disk. A snapshot is also taken before anything replaces all your notes. A gold dot on Data means nothing has been saved outside this browser for a week.

Moving off Google Keep? Download your Keep data from Google Takeout, unzip it, then Data → Import Google Keep and select everything in the Keep folder (ctrl+a) - the .json notes plus their pictures. Labels, colors, pins, checklists, links, images and archive state come across.

images & links

Paste a screenshot (ctrl+v) anywhere to start a note with it, or into an open note to attach it. You can also drop image files onto the page, a card or an open note, or use ▨ image. Large photos are scaled to 2400px; screenshots are kept as-is. Click an image to view it full size, copy it, download it or remove it. Images are stored in this browser's IndexedDB and are included in backups and the autosave file. Links: paste a URL anywhere in a note, use + link, or select text and paste a URL over it to make [text](url).

tasks, links & history

Due dates: hover a checklist item in the editor and click ◷ to give it a day; the date picker's Clear removes it. Cards show the date, overdue items turn red, and the Reminders view and the tab badge include them. You get one heads-up a day for items due. Note links: type [[ in a note to link another note by title; clicking a link opens it (or creates it), and the editor shows which notes link back. Renaming a note offers to update links to it. History: each editing session saves the previous version; History in the editor shows what changed and restores any of the last 25. Templates: ⋯ more → Save as template, then start new notes from ▤ template or quick capture. Mark up: click a picture → ✎ Mark up for arrows, boxes, highlight, pen, text and blur.

tasks, tidying & more

Tasks (t) lists every unchecked checklist item and - [ ] line from all your notes, grouped by due date. Add a task with the box at the top (or a from anywhere): it goes into the checklist named on the right of the box - Inbox unless you pick another or make a + New checklist there (the choice sticks) - and ending it with today, tomorrow, a weekday like fri, next week or a date like 2026-11-02 sets when it’s due. by date | by list switches between date groups and one fold-out drawer per list: click a list’s name to fold it, add straight into it from its own box, or drag a task onto another list’s name to move it there. Check things off there, give them dates, or drag them to reorder - dropping onto another task takes its place and its date, and dropping on today, tomorrow or no date reschedules. Checked tasks go to completed at the bottom, where a click on the check mark restores them. Cards can be dragged in any sort order (it switches to Manual). Select notes (ctrl+click) to Merge or Print them; a checklist's ⋯ more → Move checked to “Done” files finished items in an archived Done note. Pop out keeps one note in a small window that stays on top of other apps.

🔒 Lock with password (⋯ more in the editor) encrypts a note's text and checklist in this browser (AES-GCM). The title, labels and pictures are not encrypted, and a forgotten password cannot be recovered. Email: drop .eml or Outlook .msg files (or drag a message out of Outlook) onto tack to make notes, with pictures attached. Data → Search text in pictures (off by default) reads screenshots so their text is searchable. Turning it on loads its reader the first time it runs (from the website tack was opened from, or from cdn.jsdelivr.net when tack.html is opened as a file); the pictures themselves are read in this browser and never uploaded. If it can't start, a warning says why and offers Retry. ctrl+k opens the command bar.

notes

Text notes render markdown on the card - - [ ] lines are clickable there. Checklists support indent (tab), split/merge with enter/backspace, drag to reorder, and pasting a multi-line list. Reminders fire an in-page alert while the tab is open (plus a desktop notification if allowed) and can repeat. Trash empties itself after 30 days.

search

Searches every note except trash. Terms combine with AND; prefix - to exclude. #label color:red priority:critical is:pinned is:list is:note is:done is:open is:archived is:overdue is:unlabeled has:reminder has:link has:image has:due has:text is:locked due:today due:overdue due:week has:color.

Backups

Automatic backups are snapshots kept inside this browser. They protect against mistakes and bad edits, but not against clearing browser data - for that, add a backup folder, which gets full copies including images. A folder synced by a cloud service (OneDrive, Dropbox, iCloud Drive and the like) keeps copies off this computer; that service then stores your notes. A snapshot is only taken when something changed.

History

A version is saved each time you finish editing a note that changed - the last 25 per note are kept. Restoring is undoable, and the current text is saved as a version first.

Templates

Start a note from a template with ▤ template in the note box or Template ▾ in quick capture. Save any note as a template from its ⋯ more menu. {{date}}, {{time}} and {{weekday}} are filled in when you use one.
